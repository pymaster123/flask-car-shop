# flask-car-shop
First dynamic website I built. 

This was the final project for my web applications module in year 1. 

What did I learn: 

Building this site allowed me to deepen my web application skills. Previously, the only framework I had 
experience with was Django, this allowed me to explore a different framework. 
I had a good experience with flask and look forward to more opportunities to use this framework. 

Additionally, I used bootstrap, which was also something that I had never done prior. 

The project also let me focus on databases and explore how these interact with real sites. 

Overall, building this simple, entry level website as my first web apps coursework project was a positive experience.
